## Demand arithmetic

units/day = visitors/day x location_factor x area_scale x conversion x units per transaction (model values, neutral:
before seasonality, store story, holiday and promo overlays, which Phase 2 applies per date).

- weekday: 850 x 1.00 x 1.0000 x 0.22 x 2.2 = **411.400 units/day**
- weekend: 1450 x 1.00 x 1.0000 x 0.22 x 2.2 = **701.800 units/day**
- area_scale = area_sqm / Denver area_sqm (StoryCalendar.areaScale, reference store dec-us-denver): 1.0 for Denver.
- Department split: value share = StoryCalendar.departmentSalesTargets x seasonal department weight read at 2026-11-17, renormalised; units = value / demand-weighted mean price, renormalised to the total above.
- Within a department: category unit mix, then Zipf (exponent 1.10, rank offset 40.0) over styles x price^-0.5, then the size curve (`size_curve.allocate`, floored so no EAN is zero).

## Where the brief's numbers and the data disagreed

- Shoe boxes at the brief's ~4 facings/m cannot hold a 9+ size run on one level at one facing per EAN (40 of 67 footwear styles): 6/m used.
- Folded apparel 5/m (brief ~4/m) for the same reason (24 apparel styles have 8-15 sizes).
- Hanging: brief's 10 per facing at 25 slots/m is 250 garments a metre of rail; 2 garments per 4 cm slot-facing used.
- Bikes: 5 facings/m (3 across x 2 deep in a floor bay) so a frame-size run fits one level; 1.5/m left the two cycling wall bays empty.
- Total floor capacity (~30652 units) is about twice the 15,005 EPCs Denver holds today; the plan is a target, Phase 3 plans the transition.
- Department space cannot follow demand across departments (rule 1 fixes 16 fixtures each); it does inside each department.
- General (17 EANs) cannot use 16 fixtures at <= 6 facings per EAN: it takes what it needs and the rest spills over from hike_camp (above).
- Feature fixtures (islands, round rack, accessories walls, impulse, checkout) repeat styles already placed in a department (block > 1).
- Runs wider than any level of their class go off the floor (listed above).
